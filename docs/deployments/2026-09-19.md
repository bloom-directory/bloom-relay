## Evidence

Delegated NS and restrictive parent CAA are visible. Both IAM identities can
read the delegated zone; real UPSERT/DELETE diagnostic records proved their
allowed A/TXT writes and cross-role AccessDenied results. Diagnostic records
were removed. No installation was enrolled.

All four core services report private readiness 200. PostgreSQL peer identities
match each service, and API/gateway cannot read DNS credential source files.
The database has six migrations and the restore witness is group-private outside
the PostgreSQL data directory. Database, backend TLS and diagnostics bind only
to loopback. External control TLS validates and negotiates HTTP/2; both backend
TLS listeners validate with ALPN h2. Public bootstrap routes return 503 through
an explicit HAProxy enrollment gate. Certbot simulated renewal with deploy hooks
passed; all four private readiness endpoints and external TLS remained healthy
after the API/gateway restart and HAProxy reload.
